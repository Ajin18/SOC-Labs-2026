# SOC Fundamentals 

## About

I completed the SOC Fundamentals course on LetsDefend as part of my cybersecurity learning journey. This course helped me understand the basic concepts of a Security Operations Center (SOC) and how security analysts work to monitor, detect, and investigate potential security threats.

## What I Learned

* Fundamentals of a Security Operations Center (SOC)
* Roles and responsibilities of SOC analysts
* Basic concepts of security monitoring and threat detection
* Understanding security alerts and potential threats
* Introduction to security incident investigation
* The importance of incident response in cybersecurity
* How SOC teams contribute to an organization’s security

## Skills Developed

* SOC fundamentals
* Security monitoring concepts
* Alert analysis fundamentals
* Threat detection awareness
* Incident response fundamentals
* Cybersecurity investigation concepts

## Key Takeaways

This course helped me build a foundation in SOC operations and understand how security analysts contribute to identifying and responding to security threats.

As I work toward becoming a SOC Analyst Tier 1, I plan to strengthen these fundamentals through hands-on labs, security alert investigations, and blue team exercises.
