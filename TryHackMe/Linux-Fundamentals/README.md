# TryHackMe - Linux Fundamentals

## Overview

I completed the Linux Fundamentals room on TryHackMe as part of my cybersecurity and SOC Analyst learning journey.

This room helped me understand the basics of Linux and gave me practical experience using the Linux command line. I also learned how Linux systems are organized, how to work with files and directories, and how permissions, processes, and logs work.

## Topics I Practiced

During this room, I worked with:

* Linux command line
* Files and directories
* File permissions
* Users and groups
* Basic system administration
* Processes
* SSH
* Package management
* Searching and filtering files
* Linux logs
