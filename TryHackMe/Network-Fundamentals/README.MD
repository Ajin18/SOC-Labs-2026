## Key Takeaways
- The OSI Model explains how data travels across a network.
- Every device on a network has an IP address.
- MAC addresses uniquely identify network interfaces.
- TCP provides reliable communication, while UDP is faster but does not guarantee delivery.
- DNS translates domain names into IP addresses.
- DHCP automatically assigns IP addresses to devices.
- HTTP is used for web communication, while HTTPS encrypts the data.
- ICMP is used for network diagnostics, such as the `ping` command.
- Network ports help identify specific services running on a device.
