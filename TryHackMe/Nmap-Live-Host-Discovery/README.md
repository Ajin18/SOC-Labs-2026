## Nmap
Nmap (Network Mapper) is a network scanning tool used for network discovery and security auditing.

It can help identify:

* Live hosts
* Open ports
* Running services
* Operating systems
* Network information

## Key Takeaways
The main thing I learned from this lab is that host discovery is an important part of network reconnaissance. Before scanning ports and services, identifying which hosts are actually active can make the assessment more efficient.

I also learned that different networks may respond differently to discovery probes, so understanding multiple Nmap discovery techniques is useful when performing authorized security assessments
