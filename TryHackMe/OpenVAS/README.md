## OpenVAS

OpenVAS (Open Vulnerability Assessment Scanner) is a vulnerability scanning tool used to identify security weaknesses in systems and applications.

It can help security professionals discover:

* Known vulnerabilities
* Misconfigured services
* Security weaknesses
* Outdated software
* Potential attack vectors
