#  Snort
I completed this room as part of my cybersecurity learning journey, with a focus on understanding how intrusion detection systems work and how Snort can be used to detect and analyze suspicious network activity.

## About the Room

The Snort room provides hands-on practice with Snort, an open-source network intrusion detection and prevention system (IDS/IPS).

During the room, I worked with Snort rules, network traffic, alerts, and different detection techniques. The practical exercises helped me understand how security monitoring can be used to identify potentially malicious activity.

## What I Learned

* Basics of Snort and its purpose in network security
* Difference between IDS and IPS
* How Snort rules are structured
* How to write and understand Snort rules
* How Snort analyzes network traffic
* How Snort generates alerts
* Using Snort to detect suspicious network activity
* Understanding different types of network traffic
* Basic packet and traffic analysis
* Importance of network monitoring in cybersecurity

## Practical Skills

Through the hands-on exercises, I gained practical experience with:

* Snort command-line usage
* Snort configuration and rule files
* Network traffic analysis
* Writing detection rules
* Investigating Snort alerts
* Identifying suspicious traffic patterns
* Basic IDS/IPS concepts

## Key Takeaways  

One of the main things I learned from this room is that network security is not only about blocking attacks. It is also important to monitor network activity, understand what normal traffic looks like, and identify unusual behavior.

Working with Snort gave me a better understanding of how security tools can detect activity based on predefined rules and how those alerts can be investigated further.
